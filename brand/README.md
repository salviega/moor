# Moor — brand kit

## The mark

The symbol is a **bollard with a line**: the arc is the fixed mooring, the
horizontal stroke is the rope that holds. It reads as "something that stays
where it is" — the product's central argument — and at the same time as an
abstract M.

- `logo.svg` / `logo-dark.svg` — horizontal: symbol and wordmark
- `mark.svg` / `mark-dark.svg` — symbol only
- `apps/live-app/public/favicon.svg` — symbol on an ink tile, for the tab

Use the `-dark` version on dark backgrounds: the rope switches from ink to
paper, the brass stays. In the Live App the same drawing is
`src/components/logo.tsx`, with the rope on `currentColor`.

## Colour

| Role  | Hex       | Use                                              |
| ----- | --------- | ------------------------------------------------ |
| Ink   | `#0A0E14` | Main background; text on light surfaces          |
| Paper | `#F4F1EA` | Text on dark surfaces; light surfaces            |
| Brass | `#D99A2B` | The one accent: primary action, live data        |
| Slate | `#6B7785` | Secondary text, borders, metadata                |

Brass is the only accent. Green and red are reserved for financial meaning —
gain/loss, success/error — never decoration.

## Clear space

Leave around the logo a margin equal to the height of the symbol's arc.
Minimum size: 16 px for the symbol, 96 px wide for the horizontal logo.

## What not to do

- Do not rotate, tilt or apply gradients to the symbol
- Do not change the stroke weight (7 units on a 64 grid)
- Do not set long text in brass on ink (insufficient contrast); brass is for
  accents and thick elements
- Do not place the logo over images without a contrast layer

## Type

The wordmark is hand-drawn (geometric monoline). For the interface, any
geometric grotesque with good tabular figures works: Inter Tight, Söhne or
Geist. Use `font-variant-numeric: tabular-nums` on every financial figure.
